# SUPABASE SETUP — Global Leaderboard

The game works fully offline with local records. To enable the **global leaderboard**, follow these one-time steps (free tier is enough).

## 1. Create a project

1. Go to [supabase.com](https://supabase.com) and create a free account + project.
2. Open your project dashboard.

## 2. Run the SQL

Open **SQL Editor** in the dashboard, paste this, and click **Run**:

```sql
create table if not exists leaderboard (
  id                  bigint generated by default as identity primary key,
  callsign            text not null default 'OPERATOR',
  campaign_id         text not null,
  score               int not null default 0,
  rank                text not null default 'Rookie',
  time_seconds        int not null default 0,
  hints_used          int not null default 0,
  incorrect_attempts  int not null default 0,
  ending              text not null default '',
  created_at          timestamptz not null default now()
);

alter table leaderboard enable row level security;

create policy "public read" on leaderboard for select using (true);
create policy "public insert" on leaderboard for insert with check (true);

create index if not exists leaderboard_campaign_score_idx
  on leaderboard (campaign_id, score desc);

-- Optional: percentile RPC (shows "Top X%" on the ending screen)
create or replace function leaderboard_percentile(campaign_id text, p_score int)
returns float language sql as $$
  select case when count(*) = 0 then 0
    else round(100.0 * count(*) filter (where score > p_score) / count(*)::float, 1) end
  from leaderboard where campaign_id = leaderboard_percentile.campaign_id;
$$;
```

## 3. Wire in your keys

Open `src/services/supabaseConfig.ts` and paste your values:

```ts
export const SUPABASE_URL: string = 'https://YOUR-PROJECT.supabase.co';
export const SUPABASE_ANON_KEY: string = 'eyJhbGciOi...';
```

(These are the **anon/public** keys from Project Settings → API — safe for a static site, protected by the read/insert-only policies above.)

Then rebuild/redeploy. Done — scores now sync to the global board, with silent fallback to local records if the uplink ever fails.
